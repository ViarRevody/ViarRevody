Учусь в МТУСИ на кафедре интеллектуальных систем в управлении и автоматизации. Пишу бэкенд на Java и Spring Boot, сейчас ищу стажировку бэкенд-разработчиком.

Основной проект сейчас YandexMarketDemo. Это сервис доставки еды на микросервисах: заказы, оплата и доставка живут в отдельных сервисах и общаются через Kafka, база PostgreSQL поднимается в Docker. Для него есть iOS-приложение на Swift. На его основе делаю курсовую по базам данных.

В универе ещё много embedded и автоматизации: ПЛК, микроконтроллеры, ассемблер Эльбрус. Так что железо меня тоже не пугает.
